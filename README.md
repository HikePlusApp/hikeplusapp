# HIKE+ V.01 — Version officielle

Version officielle V.01 de HIKE+.

## Contenu
- Application HIKE+ en français
- Navigation GPS HIKE+
- Départ à 150 m
- Choix Google Maps / Waze pour rejoindre le départ
- Pop-ups intégrées à l'application
- Mode sombre
- PWA installable
- Parcours GPX inclus dans `gpx/`
